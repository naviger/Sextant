TROUBLESHOOTING QUICK REFERENCE
================================================================================

Docker not running?
  → macOS: open /Applications/Docker.app
  → Linux: sudo systemctl start docker

Port already in use?
  → Check: lsof -i :[port]
  → Kill: kill -9 [PID]
  → Change: Edit docker-compose.yml

Services won't start?
  → Check logs: ./scripts/logs.sh [service]
  → Rebuild: docker-compose build --no-cache
  → Try again: ./scripts/start.sh

Ollama won't download models?
  → Wait longer (first time can take 5-30 minutes)
  → Check: docker-compose ps ollama
  → Logs: ./scripts/logs.sh ollama
  → Restart: docker-compose restart ollama

More issues?
  → See: docs/TROUBLESHOOTING.md
  → Or: QUICK_REFERENCE.md
