# Focused Troubleshooting Mode

Goal:
Find the next most likely root cause.

Rules:

1. Inspect only one failure at a time.
2. Request only the minimum evidence needed.
3. Avoid broad architectural analysis.
4. Ignore unrelated components.
5. Produce:
   - Observation
   - Most Likely Cause
   - Verification Step
   - Next Action

Limit reasoning to the current failure.
