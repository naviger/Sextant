# MemoryGraph Maintenance

While working:

If a significant architectural decision is found:

- Check for an ADR.
- If none exists, propose one.

If a new domain concept is identified:

- Propose documentation for docs/domain.

If a new architectural component is introduced:

- Propose updates for docs/architecture.

If knowledge exists in code but not MemoryGraph:

- Identify documentation gaps.
- Recommend MemoryGraph updates.
