# Color System

## Summary

The system uses a restrained, oceanic palette to convey confidence, direction, and sophistication. The palette is designed for strategic views and executive readability, with each color carrying a specific semantic weight.

## Key Rules

- Use a muted, professional palette rather than saturated consumer UI colors.
- Reserve accent colors for strategic emphasis, not decorative clutter.
- Maintain strong contrast for executive readability and analytical clarity.
- Use color to reinforce navigation semantics: direction, alignment, and signal intensity.

## Allowed Patterns

- Midnight Ocean for primary headings and strong separators.
- New England Fog for secondary text and nuanced separators.
- North Atlantic Blue for primary action and navigation direction.
- Horizon Teal for AI, flow, coordination, and alignment.
- Celestial Gold for executive emphasis and strategic prioritization.
- Sea Salt, Fog, Slate, and Deep Slate for background and neutral support.

## Forbidden Patterns

- Neon colors or flashy brand accents.
- Color overload across strategic surfaces.
- High-saturation UI without semantic purpose.
- Using color as the sole carrier of meaning without supporting text or structure.
