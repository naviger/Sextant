# Visual Metaphors

## Summary

The product uses nautical and celestial metaphors to turn strategic work into a navigable system. The interface should feel like a navigation bridge with instrumentation for direction, drift, and alignment.

## Key Rules

- Use nautical charts and celestial navigation as the primary narrative.
- Keep metaphors aligned with executive strategy work, not literal shipping imagery.
- Treat alignment as a map of relationships and dependencies.
- Use navigation language as a framework for patterns, currents, bearings, and position.

## Allowed Patterns

- Navigation grids and chart-like structure.
- Bathymetric contour references.
- Bearings, courses, currents, and position fix terminology.
- Constellation-like views around a central North Star.
- Strategic relationships represented as connected paths.

## Forbidden Patterns

- Anchors, pirate imagery, ship wheels, sailboat illustrations, or clip-art nautical motifs.
- Literal maritime cliches that reduce strategic complexity.
- Generic business icons that erase the product metaphor.
- Overdecorative illustrations that make execution look whimsical.
