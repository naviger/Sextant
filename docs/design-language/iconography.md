# Iconography

## Summary

Icons should feel like precise navigation instruments, engineering diagrams, and charting tools rather than generic business or emoji-style graphics. They support strategic meaning without reducing the interface to decoration.

## Key Rules

- Prefer thin-line precision icons.
- Draw from navigation instruments, engineering diagrams, and scientific tooling.
- Use icons to reinforce direction, measurement, and signal interpretation.
- Keep icon language consistent and minimal.

## Allowed Patterns

- Bearing indicators.
- Compass arcs.
- Coordinate markers.
- Vector paths.
- Signal indicators.
- Current flow icons.
- Technical and instrument-like glyphs.

## Forbidden Patterns

- Generic business icons.
- Emoji-style devices.
- Filled, decorative icon sets.
- Literal pictograms that confuse the strategic navigation metaphor.
