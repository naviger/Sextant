│ 🔍 TROUBLESHOOTING                                                         │
└────────────────────────────────────────────────────────────────────────────┘

  Docker not running?
    → macOS: open /Applications/Docker.app
    → Linux: sudo systemctl start docker

  Port in use?
    → lsof -i :[port] to find, kill -9 [PID] to kill

  Services won't start?
    → ./scripts/logs.sh [service] to check logs
    → docker-compose build --no-cache to rebuild

  More help?
